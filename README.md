# Pixel Workbench

Personal image utility. Runs locally with Python 3.11.

## Setup

```sh
python -m pip install -r requirements.txt
```

Or use Conda:

```sh
conda env create -f environment.yml
conda activate image-workbench
```

## Command reference

```sh
python vault.py --help
```

## Tests

```sh
python -m unittest -v
```
